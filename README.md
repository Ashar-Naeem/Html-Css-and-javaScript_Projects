# JavaScript Projects with HTML & CSS 🚀

A collection of **18 frontend projects** built using **HTML, CSS, and Vanilla JavaScript**.

This repository was created to practice JavaScript through real, interactive projects while improving DOM manipulation, event handling, UI design, and problem-solving skills.

## 🎯 Purpose of This Repository

The main purpose of this repository is to move from **learning JavaScript syntax to actually implementing JavaScript in real projects**.

Instead of only practicing individual JavaScript concepts, these projects provide hands-on practice with:

* Building interactive web pages
* Connecting HTML, CSS, and JavaScript
* Manipulating the DOM
* Responding to user actions
* Updating UI elements dynamically
* Creating small application workflows
* Improving frontend problem-solving skills

## 🚀 How to Run the Projects

### 1. Clone the repository

```bash
git clone https://github.com/Ashar-Naeem/JavaScript_Projects-with-html-css.git
```

### 2. Open the repository

```bash
cd JavaScript_Projects-with-html-css
```

### 3. Choose any project

For example:

```text
Calculator/
```

### 4. Open `index.html`

You can simply open the `index.html` file in your browser.

For a better development experience, you can use **VS Code with the Live Server extension**.
